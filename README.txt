GAME IN BUDGET — WEBSITE

Open index.html in a browser to preview. To host, upload index.html, style.css, app.js and the assets folder to your web host document root. No build or installation is required.

The contact form prepares an email using the visitor email app; it does not store or send enquiries itself. Fonts load from Google Fonts with local system-font fallbacks.

To add another game, duplicate a live-game article in index.html, then update its title, description, publisher, image and Google Play links.
